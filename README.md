# Cooperative Society Loan Repayment Register

##  Project Description

The Cooperative Society Loan Repayment Register is a web-based application developed using HTML, CSS, and JavaScript. It helps cooperative societies manage loan records, repayments, outstanding balances, and member details efficiently.

---

##  Features

- Member Login
- Add Loan Records
- Search Members
- Loan Repayment Tracking
- Outstanding Balance Calculation
- Responsive User Interface
- Dashboard Statistics

---

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

##  How to Run

1. Download or Clone the project.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
